# exercício 20 - escolha estratégica de busca

## cenário

- dados inseridos de forma aleatória ao longo do tempo
- milhares de buscas por segundo

## opções analisadas

### manter desordenado e usar busca sequencial

- busca custa O(n)
- inserção é rápida, só adiciona no final
- problema: com milhares de buscas por segundo em grandes volumes, o tempo total se torna inviável

### ordenar os dados e usar busca binária

- busca custa O(log n), muito mais rápida
- inserção custa mais, pois precisa manter a ordem (O(n) para deslocar elementos)
- se as buscas acontecem com muito mais frequência que as inserções, o ganho na busca compensa o custo da inserção

## conclusão

a melhor escolha é ordenar os dados e usar busca binária.

justificativa:

- o volume de buscas é muito maior que o de inserções, então o ganho em O(log n) compensa o custo extra de manter a ordem
- em sistemas reais, estruturas como árvores binárias de busca ou listas ligadas ordenadas ajudam a equilibrar o custo de inserção e busca ao mesmo tempo, sem precisar reordenar tudo a cada mudança

## comparativo

| estratégia                     | busca    | inserção | observação                            |
| ------------------------------ | -------- | -------- | ------------------------------------- |
| desordenado + busca sequencial | O(n)     | O(1)     | simples, mas lento para muitas buscas |
| ordenado + busca binária       | O(log n) | O(n)     | eficiente se buscas são frequentes    |
