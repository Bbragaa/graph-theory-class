# Escolha de Algoritmos de Busca

## Cenário

- **Lista A:** [34, 7, 23, 89, 12, 55, 1, 67, 90, 18] (não ordenada)
- **Lista B:** lista com 1.000.000 elementos ordenados

## Lista A (não ordenada)

**Algoritmo escolhido:** Busca sequencial

**Justificativa:**
A lista não está ordenada, então não dá para usar busca binária diretamente.

**Complexidade:**
- Busca sequencial: O(n)
- Busca binária: O(log n), mas precisa ordenar antes

**Custo de ordenação:**
Para usar busca binária, seria preciso ordenar o vetor antes, com custo O(n log n).
Como a lista tem só 10 elementos, não compensa ordenar.

**Conclusão:**
Para listas pequenas e não ordenadas, a busca sequencial é mais simples e suficiente.


## Lista B (ordenada com 1.000.000 elementos)

**Algoritmo escolhido:** Busca binária

**Justificativa:**
A lista já está ordenada, então a busca binária pode ser usada sem custo extra.

**Complexidade para 1.000.000 de elementos:**
- Busca sequencial: até 1.000.000 comparações
- Busca binária: cerca de 20 comparações (log₂(1.000.000) é aproximadamente 20)

**Conclusão:**
Para listas grandes e já ordenadas, a busca binária é muito mais eficiente.



## Conclusão Geral

A escolha do algoritmo depende de três fatores:
- Se a lista está ordenada
- O tamanho da lista
- O custo de ordenação

| Lista   | Situação               | Algoritmo Ideal  |
| ------- | ---------------------- | ---------------- |
| Lista A | Pequena e não ordenada | Busca Sequencial |
| Lista B | Grande e ordenada      | Busca Binária    |
