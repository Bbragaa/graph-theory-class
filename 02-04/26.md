# exercício 26 - simulação de pior caso

## descrição

vetor não ordenado com 500 elementos. o exercício analisa dois extremos da busca sequencial:

- melhor caso: elemento na primeira posição
- pior caso: elemento na última posição ou ausente

---

## código

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define TAMANHO 500

int main()
{
  int vetor[TAMANHO];
  int busca, comparacoes, posicao;

  srand(time(NULL));
  for (int i = 0; i < TAMANHO; i++)
    vetor[i] = rand() % 1000;

  /* melhor caso: elemento na primeira posição */
  busca = vetor[0];
  comparacoes = 0;
  posicao = -1;

  for (int i = 0; i < TAMANHO; i++)
  {
    comparacoes++;
    if (vetor[i] == busca)
    {
      posicao = i;
      break;
    }
  }

  printf("melhor caso\n");
  printf("valor buscado: %d\n", busca);
  printf("posição: %d\n", posicao);
  printf("comparações: %d\n\n", comparacoes);

  /* pior caso 1: elemento na última posição */
  busca = vetor[TAMANHO - 1];
  comparacoes = 0;
  posicao = -1;

  for (int i = 0; i < TAMANHO; i++)
  {
    comparacoes++;
    if (vetor[i] == busca)
    {
      posicao = i;
      break;
    }
  }

  printf("pior caso - elemento na última posição\n");
  printf("valor buscado: %d\n", busca);
  printf("posição: %d\n", posicao);
  printf("comparações: %d\n\n", comparacoes);

  /* pior caso 2: elemento não existe */
  busca = 9999;
  comparacoes = 0;
  posicao = -1;

  for (int i = 0; i < TAMANHO; i++)
  {
    comparacoes++;
    if (vetor[i] == busca)
    {
      posicao = i;
      break;
    }
  }

  printf("pior caso - elemento não existe\n");
  printf("valor buscado: %d\n", busca);
  printf("resultado: não encontrado\n");
  printf("comparações: %d\n\n", comparacoes);

  return 0;
}


## análise

melhor caso: 1 comparação. o elemento já está no início.

pior caso: 500 comparações. o programa percorre o vetor inteiro.

o pior caso faz 499 comparações a mais que o melhor caso.

complexidade da busca sequencial:

- melhor caso: O(1)
- pior caso: O(n)
- caso médio: O(n), percorrendo cerca de metade dos elementos

para vetores grandes, a busca sequencial pode ser lenta quando o elemento esta no final ou nao existe.
